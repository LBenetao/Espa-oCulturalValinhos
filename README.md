Centro Cultural Vicente Musselli: Site Institucional

Site institucional para o Centro Cultural Vicente Musselli (Casa da Cultura de Valinhos), em Valinhos, SP. Página única, responsiva, feita com HTML e CSS puros, sem dependências e sem etapa de build.

Objetivo

Apresentar o espaço cultural à comunidade, divulgar as atividades e a agenda e facilitar o contato e a visita.

Estrutura da página
Seção	Conteúdo
Início	Título, apresentação curta e destaque visual inspirado no arco da fachada
Sobre	História e papel do espaço na cidade
Atividades	Música, dança, teatro, artes e cultura popular
Agenda	Lista de eventos e avisos
Comunidade	Chamada para o grupo do Facebook
Contato	Endereço, horário, telefone e e-mail
Como usar
Baixe o arquivo centro-cultural-vicente-musselli.html.
Abra no navegador (duplo clique) ou hospede em qualquer serviço de páginas estáticas, como GitHub Pages ou Netlify.

Não há nada para instalar.

Conteúdo a ser preenchido

Alguns dados não estavam disponíveis e estão marcados no código. Substitua antes de publicar:

Contato: endereço, horário, telefone e e-mail (campos entre colchetes).
Agenda: os três eventos são exemplos; troque pelos eventos reais.
Atividades: confirme as modalidades, turmas e horários oficiais.

Para localizar rapidamente, busque por [ e por Exemplo no arquivo.

Personalização

As cores e o tema ficam nas variáveis CSS no início do arquivo (:root):

css
--green:#1e6b45;  /* cor principal */
--sky:#8ec5e8;    /* azul-céu */
--sun:#f2b632;    /* amarelo */
--red:#d9483b;    /* vermelho */

O modo escuro é aplicado automaticamente conforme a preferência do sistema do visitante.

Design
Paleta: tirada do mural da fachada (verde, azul-céu, amarelo, vermelho).
Tipografia: Bricolage Grotesque nos títulos e Figtree no texto, via Google Fonts, com fontes do sistema como alternativa.
Acessibilidade: foco visível no teclado, contraste adequado nos dois temas, lang="pt-BR" e respeito à preferência de movimento reduzido.
Responsividade: layout adaptado de celular a desktop.
Tecnologias
HTML5
CSS3 (variáveis, grid, flexbox, media queries)
